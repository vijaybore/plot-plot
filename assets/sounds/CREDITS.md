# Sound credits

- `dice_roll.mp3` — dice rattle/roll SFX, sourced from the MIT-licensed
  `roll-a-die` project (https://github.com/chukwumaijem/roll-a-die),
  originally credited there to http://commons.nicovideo.jp/material/nc93322.
- `background_music.mp3` — "Happy Life" (re-encoded to 128kbps, cover art
  stripped), from the Royalty-Free-Music-Pack by Effa Studios
  (https://github.com/effacestudios/Royalty-Free-Music-Pack,
  www.effacestudios.com).

Swap either file out at any time — just keep the same filenames
(`assets/sounds/dice_roll.mp3`, `assets/sounds/background_music.mp3`) and
everything in `SoundService` keeps working with no code changes.
